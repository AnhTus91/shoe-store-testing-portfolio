# Shoe Store Web Application - Software Testing Project

Academic group project for the **Software Quality Assurance** course at HUFLIT. The project focuses on manual testing for a shoe-store web application, including functional testing, integration testing, test execution, and defect tracking.

> This repository contains testing documentation only. The application source code is not included.

## Project overview

- **System under test:** Shoe-store e-commerce web application
- **Project type:** Academic group project
- **Team:** Group 06 - 5 members
- **My contribution:** 20%
- **Role:** Student Tester / Team Member
- **Testing approach:** Manual functional testing, integration testing, UI and cross-browser checks
- **Defect management:** Trello

## Main functions tested

- User registration, login, logout, and password recovery
- Product search, product display, and product details
- Shopping cart, checkout, orders, and invoices
- User profile and account management
- Administration of products, categories, colors, taxes, comments, and orders
- Revenue reports

## Testing activities

- Analyzed system functions and defined the testing scope
- Created test checklists, test scenarios, and test cases
- Prepared test data, preconditions, test steps, and expected results
- Executed functional and integration test cases
- Recorded Pass/Fail results and tracked defects
- Evaluated test results and proposed improvement recommendations

## Testing summary

| Test type | Test cases | Executed | Defects found |
| --- | ---: | ---: | ---: |
| Functional testing | 167 | 146 (87%) | 21 |
| Integration testing | 27 | 23 (85.2%) | 4 |

The main defects were concentrated in checkout/order processing, password recovery, product search, and interactions between related modules.
